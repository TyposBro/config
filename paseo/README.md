# Paseo OpenCode Theme & UI/UX

Brings OpenCode's aesthetic and Markdown color coding to Paseo:
- **Obsidian & Catppuccin Mocha Dark Palette** (`#11111b`, `#181825`, `#1e1e2e`, `#313244`)
- **Semantic Markdown AST Color-Coding:**
  - Headings (`h1`-`h6`): Mauve / Soft Purple (`#cba6f7`)
  - Bold / Strong: Warm Peach / Orange (`#fab387`)
  - Italic / Em: Soft Yellow (`#f9e2af`)
  - Inline Code: Mint Green (`#a6e3a1`) on tinted dark pill
  - List Markers (`1.`, `2.`, `•`): Sapphire Blue (`#89b4fa`)
  - Blockquotes: Mauve accent border with translucent background
  - Dividers: Subtle crisp border (`#313244`)
- **Modern UI Layout:** Refined user message bubble, sleek thinking block accordion, floating composer with glowing focus ring, and thin rounded scrollbars.

## Installation

```bash
bash ~/config/paseo/install.sh
```

To verify:
```bash
bash ~/config/paseo/verify.sh
```

To uninstall / revert:
```bash
bash ~/config/paseo/uninstall.sh
```
